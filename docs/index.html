This browser can't use Bluetooth. On Android, open this page in Chrome (Bluetooth and Location on). On iPhone, use the free Bluefy browser app. On a PC, use Chrome or Edge.
How to use
  1. Power the ESP32 running one of the 10 projects.
  2. Tap Connect and pick the device named IOT-P0x-xxxx.
  3. Open Setup, enter the PIN (default 1234), then your Wi-Fi and cloud keys.
  4. Watch Live data and use Control. Every message is in Log.
